# Infernal Altar

The **Infernal Altar** is an ancient, dome-shaped structure found in the [Infernal Dunes](https://stardust-labs-mc.github.io/incendium-wiki/biomes/voltaic-heap/) biome, used as the summoning grounds and arena for the [Hovering Inferno](https://stardust-labs-mc.github.io/incendium-wiki/bossess/hovering-inferno/). It consists of a central interior contains a summomning altar with obfuscated instructions on summoning the inferno, surrounded by representations of each Incendium biome, and a basement level with loot and vaults unlocked from defeating the Hovering Inferno.
